# Design and Analysis of Algorithms

This repository contains solutions to basic problems from Design and Analysis of Algorithms (DAA), focusing on algorithm execution, data structures, and complexity analysis.

## Tasks

### Task 1 — Searching and Sorting
Find the largest element in a given list, count the comparisons, and sort the elements in ascending order.

### Task 2 — Stack and Queue
Demonstrate task processing using Stack (LIFO) and Queue (FIFO), including a printer queue example.

### Task 4 — Algorithm Complexity
Analyze single and nested loops by counting their executions and understanding their time complexity.
